# The Mari Daily — CMS edition

This version is designed for GitHub Pages + Pages CMS.

## What you get
- Custom pink magazine-style design
- Clickable sections: Books, Poetry, TV, People, My Writing, Memes
- Individual article pages
- Cover images and images inside articles
- A CMS dashboard where you can create/edit posts and upload media
- No separate database

## Publishing setup
1. Create a GitHub account.
2. Create a public repository named `YOURUSERNAME.github.io`.
3. Upload all files in this folder to the repository.
4. Enable GitHub Pages from Settings → Pages.
5. Open `https://YOURUSERNAME.github.io`.
6. Open Pages CMS, sign in with GitHub, install its GitHub App for the repository, and start editing.
